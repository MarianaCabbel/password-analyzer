Password Strength Analyzer

Checks strength locally in your browser, and separately checks whether the password has appeared in a known data breach — using k-anonymity, so the full password or its full hash is never sent over the network.

    How the breach check works: your password is hashed with SHA-1 entirely in your browser. Only the first 5 characters of that hash are sent to the Have I Been Pwned API — it returns every hash suffix that shares that prefix (usually 400–800 of them), and the match happens locally. The server never sees your password or its full hash. This is the same k-anonymity model used by real breach-checking tools.
    Nothing typed here is stored — there's no backend and no database. This tool runs entirely in your browser and only makes one outbound request (the 5-character hash prefix) to the public Have I Been Pwned API.
