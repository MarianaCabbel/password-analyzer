SUGGESTIONS

    How the breach check works: your password is hashed with SHA-1 entirely in your browser. Only the first 5 characters of that hash are sent to the Have I Been Pwned API — it returns every hash suffix sharing that prefix (usually 400–800), and the match happens locally. The server never sees your password or its full hash.

    Nothing typed here is stored — there's no backend and no database. This tool runs entirely in your browser and only makes one outbound request (the 5-character hash prefix) to the public Have I Been Pwned API.
